# Urban quality context package

**Package state:** research only; no external feature layer is bundled.
**Audit date:** 2026-09-23.
**Baseline:** this directory has no dependency on or edits to `astana-v1.json`.

See [`docs/enrichment/urban-quality/README.md`](../../../../../docs/enrichment/urban-quality/README.md)
for the source-by-source audit, status decisions, evidence and acceptance
gates. That document is the source register for this package.

No source data was copied here because this audit did not establish both a
usable Astana-level extract and clear rights to redistribute it. This avoids
shipping stale or license-ambiguous data as if it were verified. A later
accepted layer should have its own file plus source ID, retrieval time,
reference period, checksum, CRS, transformation description, quality report,
attribution, and license/terms record. Keep any ODbL-derived database clearly
separated and review share-alike obligations before combining it with other
data.

This package is descriptive map context only. It does not add indicator
values, recalculate district scores, or assert that facility counts measure
capacity, access, safety, service quality, or reliability.

# Русский и казахский интерфейс

По умолчанию используется русский (`ru`), независимо от языка браузера.
Переключатель «Русский / Қазақша» находится в верхней панели. Выбор сохраняется
в `localStorage` под ключом `stikerai.language`; казахский имеет код `kk`.
Неизвестное значение приводит к русскому языку. Если хранилище недоступно,
переключатель продолжает работать до перезагрузки страницы.

`frontend/src/i18n.tsx` содержит подписку React на язык, переключатель, функции
`t` и `tr`, обновление `html.lang`, заголовка страницы и выбор числовой локали.
Русские строки служат исходным словарём. Казахские переводы находятся в
`frontend/src/locales/kk.ts`. Для интерполяции используются нумерованные
параметры `{0}`, `{1}` через тег `tr` — порядок параметров может отличаться.

Переведены элементы интерфейса, направления, показатели, названия мероприятий
и районов, известные сообщения API, элементы карты и вспомогательных панелей.
Переключение не пересоздаёт приложение, не меняет ID объектов, не отправляет
решения на сервер и не сбрасывает выбранный сценарий.

Произвольные названия команд, ответы AI и тексты внешних источников сохраняются
на языке оригинала. Для неизвестного текста `t` возвращает исходное значение.
Язык контента внешнего видеоплеера и картографических подложек определяется
поставщиком; эти данные не переводятся локальным словарём.

Проверки из папки `frontend`:

```sh
npx tsc --noEmit
npx playwright test e2e/i18n.spec.ts
```

Браузерные тесты используют тестовый API из существующей конфигурации Playwright.
Проверяются язык по умолчанию, сохранение выбора, сохранность решений, мобильный
переключатель, неизвестный код языка и недоступное хранилище.
